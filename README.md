# 📝 TaskMaster Pro

> **Advanced Productivity & Kanban Task Management Application** with category filtering, priority metrics, persistent local storage, dark mode, and deadline tracking.

---

## 🌟 Key Features

- 📋 **Multi-Category Task Management**: Work, Personal, Shopping, Health, and custom labels.
- ⚡ **Priority Tagging & Due Date Reminders**: High, Medium, Low urgency tags.
- 📊 **Real-time Analytics Dashboard**: Total tasks, completion percentage, and streak tracker.
- 🌙 **Modern Glassmorphism Design & Dark Theme**: Sleek typography and responsive UI.
- 💾 **Instant LocalStorage Persistence**: Keeps your tasks saved automatically across browser sessions.
